# D-LOGIS 문서 출력 기준

## 기본 원칙

기관 제출용 문서는 CSV가 아니라 Excel XLSX 형식으로 저장합니다.

- CSV는 단일 표만 저장되어 날짜 서식, 필터, 고정창, 색상, 시트 구분이 사라집니다.
- 기관 제출 기본 파일은 `기관보고서 Excel`입니다.
- 반복 텔레메트리 원본, 명령 원본, 중복 임무정보는 기본 보고서에서 제외합니다.
- 필요 시 화면별 축약 보고서인 `배송증빙 Excel`, `운영리포트 Excel`을 사용합니다.

## 출력 파일 구분

| 버튼 | 용도 | 포함 내용 |
|---|---|---|
| 기관보고서 Excel | 기관 제출 기본 파일 | 제출요약, 임무별 종합, 운항안전 요약, 검증승인 요약, 배송증빙, 안전경보 조치, 자산배터리, 용어기준 |
| 배송증빙 Excel | 배송 완료 증빙만 별도 제출 | 제출요약, 배송증빙, 용어기준 |
| 운영리포트 Excel | 내부 운영회의·성과보고 | 제출요약, 임무별 종합, 운항안전 요약, 배송증빙, 안전경보 조치, 자산배터리, 용어기준 |

## 제외한 항목

기본 기관보고서에는 다음 원본 데이터를 반복 출력하지 않습니다.

- 초 단위 또는 5초 단위 텔레메트리 전체 로그
- 동일 Mission ID가 반복되는 명령 원본 전체
- 같은 드론·배터리 정보가 여러 시트에 반복되는 원시 테이블

대신 임무별 최종 수신값, 경보 건수, 검증 상태, 증빙 유무, 자산 현황으로 요약합니다.
