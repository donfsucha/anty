# D-LOGIS CONTROL 변경이력

## 3.0.0

- 조치 우선순위 중심 통합관제 대시보드로 재구성
- 관제자·조종자·수령인 역할별 사용동선 단순화
- 운영 수치 소수점 한 자리 저장·표시 표준화
- 좌표 화면 DMS 0.1초 표시 및 WGS84 6자리 원본 보존
- KST 화면시각 및 ISO 8601 원본시각 저장
- 드론 전송시각·수신시각·명령 요청·ACK·적용확인시각 분리
- 비행로그·명령이력·경보·배터리·점검·증빙·감사로그 추가
- 9개 시트 XLSX 운영보고서 자동 생성
- 4단계 임무 생성 마법사 추가
- 운항 승인과 7개 비행 전 점검 추가
- 안전기준 기반 기체·배터리 자동배정 추가
- 카카오맵 무료 쿼터 우선 및 OpenStreetMap 자동 대체 추가
- Netlify 재배포 파일 및 PWA 캐시 추가
