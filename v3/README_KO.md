# D-LOGIS CONTROL V3 실운영형

드론 배송 임무, 기체, 배터리, 안전, 배송증빙과 운영기록을 Mission ID로 연결하는 웹앱입니다.

## 로컬 실행

VS Code에서 `v3` 폴더를 열고 터미널에서 실행합니다.

```bash
python3 -m http.server 5500
```

Chrome 주소창에서 다음 주소를 엽니다.

```text
http://localhost:5500
```

## V3 핵심 기능

- 조치 우선순위 중심 통합관제 대시보드
- 운영 수치 소수점 한 자리 고정
- 좌표 DMS 표시: 초 단위 소수점 한 자리
- 정확한 KST 날짜·시간 기록
- 드론 전송시각, 수신시각, 명령 요청, ACK, 적용확인시각 분리
- IndexedDB 기반 비행로그·명령·점검·배터리 기록
- 10개 시트 XLSX 운영보고서
- 4단계 신규 임무 생성
- 관제자·조종자·수령인 역할별 동선
- 카카오맵 JavaScript SDK 연동
- 카카오맵 사용 불가 시 OpenStreetMap 자동 전환

## 숫자 표시 규칙

고도, 속도, 거리, 중량, 배터리, 온도, 통신, 풍속, 셀 편차 등 운항 수치는 소수점 한 자리로 저장하고 표시합니다.

위치 정확도를 잃지 않도록 좌표는 다음처럼 표시합니다.

```text
37°30′12.4″N
126°45′58.7″E
```

즉, 위도·경도의 긴 소수 대신 도·분·초를 사용하고 초 단위만 소수점 한 자리로 표시합니다.

## 카카오맵 설정

1. 카카오 개발자센터에서 앱을 생성합니다.
2. 해당 앱이 카카오맵 무료 쿼터 대상인지 확인합니다.
3. Kakao Map API를 활성화합니다.
4. JavaScript Key에 로컬 도메인 `http://localhost:5500`을 등록합니다.
5. 배포 후 실제 `netlify.app` 도메인도 등록합니다.
6. 앱의 `시스템설정 → 지도 설정`에 JavaScript Key를 입력합니다.

유료 API 또는 Biz Wallet을 앱에서 자동으로 활성화하지 않습니다. 키가 없거나 지도가 로딩되지 않으면 OpenStreetMap으로 자동 전환합니다.

## Excel 운영보고서

관제 화면의 `운영보고서 XLSX` 버튼을 누르면 다음 시트를 생성합니다.

1. 01_운영요약
2. 02_임무목록
3. 03_비행로그
4. 04_명령이력
5. 05_경보이력
6. 06_배터리기록
7. 07_배송증빙
8. 08_비행전점검
9. 09_감사로그
10. 10_자산현황

Excel에는 생성시각, Mission ID, 기체와 배터리 ID, 사용자, 수치, 명령 결과와 데이터 출처가 포함됩니다.

## Netlify 배포

`v3` 폴더 안에서 `index.html`이 바로 보이는지 확인한 뒤 폴더 전체를 Netlify Drop에 올립니다. `_redirects`와 `netlify.toml`이 포함되어 있습니다.

## 실제 운영 전 추가 개발

현재 V3는 브라우저 기반의 정밀 시연·업무검증 버전입니다. 실제 다중 사용자 운용에는 중앙 데이터베이스, 로그인과 권한, 서버 수신시각, 파일 저장소, MAVLink 또는 제조사 SDK 게이트웨이, 명령 ACK 재확인, 백업·암호화·보존정책이 필요합니다.
