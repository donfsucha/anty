# D-LOGIS CONTROL

드론 배송 주문·임무·기체·배터리·안전·배송증빙을 통합 관리하는 실행형 웹 앱입니다.

## 공개 실행 링크

- https://raw.githack.com/donfsucha/anty/main/index.html

## 구현 기능

- 관제센터 대시보드와 실시간 지도 시뮬레이션
- 배송임무 생성·자원 배정·비행 전 점검·이륙 승인
- 운항 시작·일시대기·재개·즉시복귀·착륙·완료
- 드론·스마트배터리·안전경보·배송증빙 관리
- 현장 조종자와 배송 수령인 모바일 화면
- 브라우저 저장, 데모 초기화, CSV·JSON 내보내기
- PWA 설치와 오프라인 캐시
- 외부 HTTPS 게이트웨이 연결시험 및 명령 API 구조

## 운영 모드

기본 실행은 안전한 시뮬레이션 모드입니다. `기체 연결` 화면에서 외부 게이트웨이 주소와 API 키를 입력하면 `/api/health` 연결시험과 `/api/commands` 명령 전송 구조를 사용할 수 있습니다.

> 실제 드론의 모터·이륙·복귀 제어는 기체, 비행컨트롤러, 통신장치, SDK 또는 MAVLink 게이트웨이와 현장 안전검증을 완료한 뒤 활성화해야 합니다.
